# Mediphera ميديفيرا — موقع Blogger كامل + استراتيجية SEO/GEO

> **مستحضرات تجميل طبية سورية بتركيبة صيدلانية من د. البتول عبود**
> موقع احترافي جاهز للرفع على Blogger (مجاني 100%) — RTL كامل، تصميم "Medical Luxury"،
> بيانات مهيكلة شاملة (Schema.org) لظهور مجاني في جوجل ومحركات الذكاء الاصطناعي.

## 📦 محتويات المستودع

```
├── mediphera-blogger-theme.xml   ★ القالب النهائي — ارفعيه مباشرة في بلوجر (كل الصور مضمّنة)
├── preview/                      ★ معاينة حية للتصميم (افتحي index.html في المتصفح)
│   ├── index.html                — الصفحة الرئيسية كما ستظهر
│   └── post.html                 — صفحة منتج كاملة (سيروم فيتامين C)
├── template/                     — مصادر القالب (للتعديل وإعادة البناء)
│   ├── theme.template.xml        — قالب Blogger (V3) الكامل
│   └── content/*.html            — الأقسام القابلة للتعديل (عن/منتجات/أسئلة/تواصل)
├── templates/                    — قوالب المحتوى لمنشورات بلوجر (انسخيها لمحرر بلوجر)
│   ├── product-post.html         ★ قالب منتج (معرض صور + مكونات + فوائد + واتساب + Schema)
│   ├── article-post.html         ★ قالب مقال توعوي (إجابة مباشرة + FAQ + Schema)
│   ├── about-page.html           ★ صفحة "عن ميديفيرا" (كيانات + FAQ)
│   └── privacy-policy.html       ★ صفحة سياسة الخصوصية
├── docs/                         — الخطط والاستراتيجيات
│   ├── 01-دليل-التركيب-الخطوة-ب-الخطوة.md   ★ ابدئي من هنا (60-90 دقيقة)
│   ├── 02-استراتيجية-SEO-GEO.md             — الكلمات المفتاحية + تثبيت الكيانات + ظهور LLMs
│   └── 03-خطة-المحتوى-12-أسبوع.md           — 24 مقالاً + 6 منتجات جاهزة بالعناوين
├── seo/robots.txt                — ملف الزواحف (يُرفق في إعدادات بلوجر)
├── assets/images/                — هوية بصرية مولدة (شعار، هيرو، 6 منتجات)
└── tools/build_theme.py          — أداة إعادة بناء القالب (بعد تغيير صور/محتوى)
```

## 🚀 البدء السريع (3 خطوات)

1. **عايني التصميم:** افتحي `preview/index.html` (أو من المعاينة الحية).
2. **ارفعي القالب:** بلوجر → القالب → استعادة → ارفعي `mediphera-blogger-theme.xml`.
3. **طبقي دليل التركيب:** `docs/01` — استبدال البيانات الشخصية، الصفحات الثابتة،
   نشر المنتجات الستة، Google Search Console.

##  ما الذي يثبّت البراند في محركات الذكاء الاصطناعي؟

القالب يحوي تلقائياً (بدون أي شيء إضافي):

- **Organization** (Mediphera): الاسم العربي، سوريا، النشاط، الحسابات.
- **Person** (د. البتول عبود): صيدلانية، مؤسس، تخصص Medical and Cosmetic Formulation.
- **LocalBusiness/MedicalBusiness**: دمشق، سوريا، ساعات العمل، الهاتف.
- **WebSite + SearchAction**: بنية الموقع والبحث الداخلي.
- **Product ×6** مع `aggregateRating` و`Review`: تغذي اقتباسات "أفضل منتجات".
- **Article + BreadcrumbList + FAQPage**: في كل مقال/منتج/قسم.
- **نصوص الكيانات** (Entity Recognition): "أفضل ماركة مستحضرات تجميل في سوريا"،
  "مستحضرات تجميل طبية سورية"، "Mediphera د. البتول عبود"، "تركيبات صيدلانية للبشرة"
  — موزعة طبيعياً في وصف المدونة، الهيرو، عن، FAQ، وصف المنتجات.

> التفاصيل الكاملة وكيفية القياس الشهري: `docs/02-استراتيجية-SEO-GEO.md`

## 🔧 إعادة بناء القالب (اختياري)

بعد تعديل أي ملف في `template/` (صورة، نص، زر):

```bash
python3 tools/build_theme.py
```

يولّد `mediphera-blogger-theme.xml` محدّثاً (مع ضغط الصور والتحقق من XML).
تحتاجين `pip install pillow` مرة واحدة.

## ⚠️ ملاحظات مهمة

- الأسعار والمراجعات والتقييمات داخل Schema **قيم مبدئية** — استبدليها ببياناتك
  الحقيقية قبل النشر (المراجعات المخترعة تضر بالثقة وخرق سياسات جوجل).
- "+15 عاماً خبرة" في قسم "عن" رقم افتراضي — حدّثيه في `template/content/about-section.html`.
- الصور المولدة هوية بصرية موحدة — يمكنك استبدالها بصور منتجاتك الحقيقية
  (في `assets/images/` ثم أعدّي البناء، أو عدّلي الروابط في تخطيط بلوجر).
- الموقع كله مجاني: Blogger + Google Search Console + (اختياري) Bing Webmaster.
